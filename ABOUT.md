# openai-codex-plugins

> Curated collection of OpenAI Codex plugin examples; a fork maintained for upstream submission.

**Family:** plugins · **Type:** tool · **Lifecycle:** experimental · **Owner:** cching-openai

## What it does
Holds example Codex plugins under `plugins/<name>/`, each with a `.codex-plugin/plugin.json` manifest and optional skills, agents, commands, hooks, `.app.json`, and `.mcp.json` surfaces. Richer examples include figma, notion, build-ios/macos/web-apps, expo, netlify, remotion, and google-slides. This is a fork of OpenAI's repo (all top contributors are OpenAI staff) kept in the org for upstream submission.
